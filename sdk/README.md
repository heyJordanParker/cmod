# cmod-sdk

Build Claude Code mods: hooks, panes, commands, tools, permissions, and an install step that CMod runs with the person's consent.

```sh
cmod new my-mod
```

`cmod new` writes a mod that depends on cmod-sdk, with a test that runs it against a fake Claude Code through `cmod-sdk/testing.js`.

The guide, the CMod plugin, and the `cmod` program live at [github.com/heyJordanParker/cmod](https://github.com/heyJordanParker/cmod).
